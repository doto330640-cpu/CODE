# 이미지 생성 프롬프트 라이브러리

자주 쓰는 장면별 기본 프롬프트입니다. `[ ]` 부분만 바꿔서 씁니다.
AI 이미지 도구는 영어 프롬프트에서 결과가 더 안정적이라 영문을 함께 적었습니다.

## 공통 스타일 (모든 프롬프트 끝에 붙임)
```
photorealistic, natural daylight, professional golf industry photography,
clean composition, no text, no logos, 16:9
```

## 1. 코스 전경 (강의·제안서 표지)
```
Aerial view of a well-maintained Korean public golf course in [season: early autumn],
lush [bentgrass] greens, mowing stripes on fairways, surrounding mountains, morning mist
```

## 2. 그린 관리 작업
```
Greenkeeper operating a walk-behind greens mower on a putting green at dawn,
dew on the grass, visible mowing pattern, close-up, shallow depth of field
```

## 3. 잔디 병해 (교육용)
```
Close-up of [dollar spot / brown patch] disease on [creeping bentgrass] putting green turf,
educational reference photo, sharp detail
```
> 병해 사진은 생성 이미지보다 실제 현장 사진이 교육 효과가 큽니다. 가능하면 `images/source/` 원본을 우선 사용합니다.

## 4. 코스관리 장비
```
Fleet of fairway mowers and utility vehicles neatly parked in a golf course maintenance facility,
organized, clean concrete floor
```

## 5. 클럽하우스·식음
```
Modern golf clubhouse restaurant interior with a window view of the 18th green,
Korean set menu on the table, warm lighting
```

## 6. 운영·서비스
```
Golf course front desk staff greeting golfers at check-in, bright lobby, professional uniforms
```
