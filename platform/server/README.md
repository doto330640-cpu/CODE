# 서버(클라우드) 구축 안내

**선택: 클라우드 관리형 서비스(Supabase 권장)** — 로그인, 권한(행 단위 보안), DB, 파일 저장을 한곳에서 제공합니다. 서버 운영 인력이 필요 없습니다.

## 권한 모델
| 역할 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 경영자(owner) | 전 코스, 모든 팀장 작업 | 사용자·코스 배정 관리, 읽기 |
| 코스팀장(manager) | 배정된 코스만 | 자기 코스 작업 체크·추가 |

접근 제한은 `schema.sql`의 RLS 정책이 DB에서 처리합니다. 화면 숨김만으로 막지 않습니다.

## 구축 순서
1. Supabase 프로젝트 생성 — 리전은 서울(ap-northeast-2). 가입은 대표님 계정으로 직접 하셔야 합니다.
2. SQL Editor에서 `schema.sql` 실행.
3. 사용자 초대(이메일) 후 `profiles`, `course_members`에 역할·코스 배정.
4. 센서 자료 적재: `tools/build_platform_data.py` 결과를 `daily_readings`로 올리는 스크립트(서비스 키 사용, 서버에서만 보관).
5. 앱에 로그인 화면과 서버 연동 연결(프로젝트 URL과 공개(anon) 키 필요 — 비밀 키는 앱에 넣지 않습니다).
6. HTTPS 주소에 앱 배포(Cloudflare Pages 등 정적 호스팅).

## 대용량 자료(드론 영상)
원본은 자체 보관하고, 화면용(타일·축소본)만 비공개 저장소에 코스별 폴더로 올려 같은 권한 규칙을 적용합니다.

## 보안 메모
- 비밀 키(service_role)는 저장소와 앱에 절대 넣지 않습니다.
- 팀장 계정은 코스별로 따로 발급합니다.
- 요금은 가입 시점의 요금표를 확인하세요(자료량과 사용자 수에 따라 달라집니다).
