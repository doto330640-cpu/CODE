# GPT 초안 → 완성 이미지 작업 절차

## 1. GPT 초안 넣기
GPT에서 만든 1차 결과물을 `drafts/gpt/` 폴더에 넣거나, Claude 대화창에 바로 붙여 넣습니다.

| 초안 종류 | 넣는 방법 |
|---|---|
| 글(목차, 슬라이드 문구, 표) | 대화창에 그대로 붙여 넣기, 또는 `.md`/`.txt` 파일로 저장 |
| GPT가 그린 이미지 | 이미지 파일을 대화창에 첨부, 또는 `drafts/gpt/`에 업로드 |
| 엑셀·수치 자료 | `.xlsx`/`.csv` 파일로 업로드 |

파일 이름 예: `drafts/gpt/2026-10-15_OO골프장_제안서_초안.md`

## 2. Claude 작업
1. 초안 내용을 검토해 구조와 메시지를 다듬습니다 (업계 용어, 수치 점검 포함).
2. 슬라이드·도식을 `images/html/`에 HTML로 작성합니다 (회사 색상과 글꼴 자동 적용).
3. `node tools/render.mjs images/html/파일.html`로 고해상도 PNG(3840×2160)를 만듭니다.
4. 결과 이미지를 대화창에서 바로 보여 드립니다.

## 3. 수정 요청
"제목 더 크게", "3번 항목 빼줘", "색을 회사 로고 색으로"처럼 말씀하시면 같은 파일을 고쳐 다시 만듭니다.
수정 이력은 Git에 남으므로 이전 버전으로 언제든 되돌릴 수 있습니다.

## 4. 최종 납품
- 슬라이드 이미지(PNG): 파워포인트·한글 문서에 바로 삽입
- 필요 시 PowerPoint(.pptx) 또는 PDF로 묶어서 제공
