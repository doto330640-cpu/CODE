# 골프장 운영·위탁 자료실

골프장 운영위탁, 코스위탁, 식음위탁 사업과 관련한 **강의 자료, 제안서, 기사 원고, 이미지**를 한곳에서 관리하는 저장소입니다.
대중골프장협회 코스관리 자문과 골프코스세미나 발행 업무에 쓰는 자료도 이곳에 함께 모읍니다.

## 폴더 구성

| 폴더 | 용도 |
|---|---|
| `lectures/` | 강의안, 세미나 발표 자료 (주제별 폴더) |
| `proposals/` | 운영·코스·식음 위탁 제안서 (골프장별 폴더) |
| `articles/` | 골프코스세미나 기사·칼럼 원고 |
| `drafts/gpt/` | GPT로 만든 1차 초안 (작업 절차: `drafts/README.md`) |
| `images/html/` | 슬라이드·도식 원본 (HTML) |
| `tools/render.mjs` | HTML → 고해상도 PNG 변환 |
| `images/prompts/` | 이미지 생성용 프롬프트 모음 |
| `images/generated/` | 생성한 이미지 결과물 |
| `images/source/` | 직접 촬영한 코스 사진 등 원본 자료 |
| `images/diagrams/` | 조직도, 공정표, 비교표 같은 도식 |
| `brand/` | 회사 로고, 색상, 글꼴 등 공통 디자인 기준 |

각 폴더의 `_template/`에 기본 양식이 있습니다. 새 자료는 양식을 복사해서 시작합니다.

## 파일 이름 규칙

```
YYYY-MM-DD_주제_버전
예) 2026-10-15_잔디병해관리_v1.md
    2026-11-02_OO컨트리클럽_운영위탁제안서_v2.md
    2026-10-15_잔디병해관리_표지_01.png
```

- 날짜를 앞에 두어 시간순으로 정렬되게 합니다.
- 띄어쓰기 대신 밑줄(`_`)을 씁니다.
- 수정본은 덮어쓰지 않고 `v2`, `v3`로 올립니다.

## 이미지 작업 방식

| 종류 | 방법 |
|---|---|
| 표지, 분위기 이미지 | AI 이미지 생성 (Canva, Figma 연결 시) — 프롬프트는 `images/prompts/`에 기록 |
| 조직도, 공정표, 비교표 | Claude가 SVG/HTML 도식으로 직접 작성 |
| 코스 현황 사진 | 현장 촬영본을 `images/source/`에 보관 후 편집 |
| 슬라이드 | Claude로 PowerPoint(.pptx) 또는 온라인 슬라이드 작성 |

> 고객 골프장의 계약 조건, 매출 자료 등 민감한 내용은 비공개 저장소에서만 다룹니다.
